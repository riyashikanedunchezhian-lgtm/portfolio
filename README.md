# Portfolio – Riyashika Nedunchezhian

A polished, dark‑mode‑first portfolio built with **Next.js (App Router), TypeScript, and Tailwind CSS**.

## Sections

- **Hero** – name, tagline, “View Projects” & “Download Resume” buttons
- **About**
- **Experience**
- **Projects** – detailed case studies + compact cards
- **Skills**
- **Education**
- **Affiliations**
- **Footer** – nav links, repeated resume download, social icons

## Getting started

```bash
# install
npm install

# dev server
npm run dev
```

Deploy with Vercel (see `vercel` config at the bottom of this file).
